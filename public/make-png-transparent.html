Make a transparent PNG

A transparent PNG is a picture with no background, so it can sit on top of any color, photo or slide. Background Killer makes one from an ordinary photo in a few clicks, for free.

How transparency works

PNG and WebP files can store an alpha channel, which says how see-through each pixel is. Where the alpha is zero, you see whatever is behind the image. JPG files have no alpha channel, so they can never be transparent.

Make one in three steps

  1. Add your photo on backgroundkiller.com.
  2. Leave the background set to transparent, which is the checkerboard swatch.
  3. Choose PNG as the format and press Download full size.

The checkerboard you see in the preview only marks the empty areas. It is not baked into the file.

Check that your file is really transparent

Open the PNG in a design tool or presentation app and place it over a colored shape. If the color shows through around the subject, the file is transparent. Many image viewers show a white or gray background instead, which can make a transparent file look solid.

Where transparent PNGs are useful

  • Slides and documents, such as Keynote, PowerPoint and Google Slides.
  • Design tools, such as Figma and Canva, for collages and mockups.
  • Websites, where a cutout can sit on any section color.
  • Stickers, labels and print layouts.

What it does not do well

Background Killer is built for photos with a clear subject. For flat logos or graphics with a single background color, a color-based eraser in an image editor can give a sharper edge. For photos with fine hair or glass, expect to touch up the edges with the Erase and Restore brush.
